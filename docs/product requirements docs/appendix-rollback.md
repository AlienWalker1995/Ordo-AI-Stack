# Appendix: Rollback Procedures

1. **Model gateway:** Point services directly to llama.cpp (`OPENAI_API_BASE=http://llamacpp:8080/v1`); `cd out && docker compose -p ordo stop model-gateway`. Restart affected services.
2. **Ops controller:** `cd out && docker compose -p ordo stop ops-controller`; the dashboard's ops actions and model switch show "control plane is not answering" and GPU leases stop being granted. Chat and MCP traffic are unaffected. No data loss.
3. **MCP registry:** Re-render from the previous `ordo.yaml`; `out/model-gateway/mcp_servers.yaml` is required and `model-gateway` fails loud if it is missing, so there is no partial-registry state to fall back to.
4. **cap_drop / read_only:** Remove it where it is declared (the service's manifest, or `ordo/render/compose.py` for a core service), re-render (`python -m ordo --source out/ordo.yaml render --out out`), then `ordo recreate <service>`.
5. **Reset OPS_CONTROLLER_TOKEN:** `openssl rand -hex 32` → update `out/secrets.env` → outside a GPU lease, `ordo recreate` ops-controller (it verifies the bearer) and every service that sends it (find them with `grep -n '${OPS_CONTROLLER_TOKEN' out/docker-compose.yml`). `ordo recreate` refuses ops-controller while the card is leased, unless the running ops-controller reports its lease state saved to disk (`state_persisted` in `/status`) and the render sets `SCHEDULER_STATE_PATH`.
6. **MCP tools:** Trim the `kind: mcp` plugins in `ordo.yaml` to a single safe server, then `ordo render` and recreate `model-gateway` (LiteLLM reads MCP servers at startup, there is no hot reload).
7. **RAG:** `cd out && docker compose -p ordo stop rag-ingestion qdrant`; remove `VECTOR_DB=qdrant` from Open WebUI env → Open WebUI uses built-in vector store. Qdrant data preserved in the `qdrant-data` named volume.
8. **Invalidate model cache** (model-gateway has no host port — go in-network or via the Caddy `/llm` edge): `docker compose -p ordo exec dashboard curl -X DELETE http://model-gateway:11435/v1/cache` (or `curl -X DELETE -H "Authorization: Bearer $LITELLM_MASTER_KEY" https://<host>/llm/v1/cache`) — forces fresh fetch from llama.cpp on next `/v1/models` call.
9. **Safe mode:** `cd out && docker compose -p ordo stop $(docker compose -p ordo config --services | grep '^mcp-') agent comfyui rag-ingestion` → llama.cpp + Open WebUI + dashboard only.
